## 🚀 Featured Projects

### 1. Campus Query AI Engine
* **Tech Stack:** Java, Spring Boot, PostgreSQL, pgvector, Ollama, Apache PDFBox, Spring Security, JWT, Swagger/OpenAPI
* **What it does:** An intelligent campus query system that ingests university PDFs using Apache PDFBox for automated request resolution. It integrates PostgreSQL with `pgvector` and Ollama to execute semantic similarity searches over document chunks, generating accurate, context-grounded answers. Fully secured with Spring Security, JWT authentication, and role-based authorization.

### 2. Expense Tracker API
* **Tech Stack:** Java, Spring Boot, MySQL, Spring Data JPA, REST APIs
* **What it does:** A robust personal finance backend managing real-time transactional data, balance calculations, and automated expense categorization. Built with normalized relational database schemas in MySQL and optimized query routines via Spring Data JPA.

### 3. Meal Finder App
* **Tech Stack:** JavaScript, HTML5, CSS3, REST API
* **What it does:** A responsive web application that integrates external endpoints from TheMealDB using asynchronous `Fetch` API calls. Features dynamic DOM manipulation for seamless search filtering and real-time recipe rendering.
